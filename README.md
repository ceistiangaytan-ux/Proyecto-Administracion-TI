# UTNACAR WASH

## Descripción del Proyecto

**Nombre:** UTNACAR WASH

**Problema a resolver:**
Una lavadora de autos necesita contar con un sistema que ayude a gestionar los vehículos y al personal, además de disponer de un sitio web para dar a conocer sus servicios a los clientes.

**Objetivo General:**
Desarrollar un sistema para la gestión de vehículos y personal de una lavadora de autos, así como un sitio web informativo que muestre los servicios, precios e información general del negocio.

**Alcance Preliminar:**
El sistema permitirá registrar la entrada y salida de vehículos, seleccionar servicios y administrar roles y permisos del personal. El sitio web mostrará información de la empresa, servicios y precios. La principal restricción del proyecto es el tiempo disponible para su desarrollo.
